# Doctrine

RBC is the deterministic rulebook cascade system for computing effective
operating constraints.

It does not own storage, transport, consensus, identity, UI, or canonical
reality.

It receives a basis and rule material.

It returns an effective view.

The effective view determines what is allowed, denied, review-gated,
admissible, inadmissible, overridable, non-overridable, inherited, expired, or
branch-compatible under the current context.

RBC is deterministic: the same basis and same rule material must produce the
same effective view.

## Core Boundary

RBC does not contain every rule.

RBC resolves relevant rule material for a specific basis.

RBC does not own authority.

RBC computes effective authority posture.

RBC does not perform actions.

RBC determines whether an action is allowed, denied, gated, provisional,
unknown, or unresolved.

RBC does not eliminate ambiguity.

RBC makes ambiguity explicit.
